Falco 2.4.0

DNS:
- DNS moved to the Hetzner Cloud DNS API (the old DNS console API was
  shut down). DNS uses your Cloud project token; no separate DNS token.
- Zones, records (RRSets), zone file import/export and primary
  nameservers for secondary zones.

Cloud:
- All projects mode: actions, detail screens and pickers use the
  right project.
- Networks are created with their subnet in one step, vSwitch subnets
  supported.
- Metrics show read/write and in/out bandwidth with fitting units.

Robot:
- Reverse DNS edits, server cancellation, rescue with stored SSH keys
  and vSwitches work again.

S3:
- Folders with spaces, downloads on all Android versions, parallel
  uploads with notifications, honest bulk delete results.

App:
- Switching accounts never shows the previous account's data.
- Language choice works on Android 8 to 12.
- Copied secrets are cleared reliably, dialogs survive rotation.
