Falco 2.3.0

Stability and safety release.

Fixes:
- No more crash when a token lacks permission for an action or Robot
  rate limits a request.
- Android 9 and 10: app lock no longer locks users out.
- Stored credentials are no longer wiped by temporary Keystore errors.
- Storage Boxes work again (new Hetzner certificates), including
  snapshot rollback, locations, status and reliable error messages.
- Primary IP creation, IP assignment, server type change, reverse DNS
  reset and load balancer algorithm change follow the current Hetzner API.
- Long lists load completely (pagination).
- Root password is shown after rebuild and server creation.

Safety:
- Reboot, shutdown, power on/off, reset, disabling backups, volume
  detach and deleting listeners, targets or DNS records ask first.

New:
- Project activity feed with all recent actions and a status filter.
- Server activity reachable from the top bar.
